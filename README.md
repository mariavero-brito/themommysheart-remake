# Mommy's Heart redesign preview

A static, clearly labeled design preview of proposed changes for themommysheart.com. It is not the official site.

- Plain HTML, CSS and JS, no build step. Hosted on GitHub Pages.
- Buttons for booking, checkout, sign-up and forms are inactive and show a "Preview only" message.
- Photos, testimonials, bio, event prices and rules are placeholders to replace with real, permitted content.
- The EN | ES switch uses draft Spanish translations for key text. They need review by a native speaker.
- The page is set to noindex and robots.txt disallows crawling.
- The building entry code is intentionally not included anywhere.
